📐 FUNDAMENTACIÓN FORMAL DE CÁLCULO MULTIVARIABLE

1. Validación de Volumen mediante Integral Triple

El recinto del centro de datos corresponde al dominio espacial tridimensional acotado:
Ω = { (x, y, z) ∈ ℝ³ : 0 ≤ x ≤ 10, 0 ≤ y ≤ 15, 0 ≤ z ≤ 3 }

V = ∭Ω dV = ∫₀¹⁰ dx ∫₀¹⁵ dy ∫₀³ dz
V = [x]₀¹⁰ × [y]₀¹⁵ × [z]₀³ = (10 - 0) × (15 - 0) × (3 - 0) = 10 × 15 × 3 = 450.00 m³

La superficie de suelo es de 10 m × 15 m = 150 m² con una altura máxima libre de 3.0 m.

2. Teorema del Valor Medio para Integrales Múltiples

Dada la distribución térmica cuadrática continua en altura T(x,y,z) = 20 + z²:

T̄ = (1 / V) ∭Ω T(x, y, z) dV
T̄ = (1 / 450) ∫₀¹⁰ dx ∫₀¹⁵ dy ∫₀³ (20 + z²) dz
∫₀³ (20 + z²) dz = [20z + z³/3]₀³ = 20(3) + 3³/3 = 60 + 9 = 69
∭Ω T dV = (10) × (15) × (69) = 150 × 69 = 10,350
T̄ = 10,350 / 450 = 69 / 3 = 23.00 °C

Interpretación: El recinto mantiene un régimen volumétrico medio ideal de 23°C dentro de las pautas térmicas ASHRAE TC 9.9 para centros de cómputo.

3. Vector Gradiente y Regla de Optimización

El vector gradiente ∇T señala la dirección de máxima tasa de crecimiento térmico:

∇T(x, y, z) = ( ∂T/∂x, ∂T/∂y, ∂T/∂z ) = ( 0, 0, 2z )
  • Puntos de menor temperatura: Ocurren en z = 0 (el piso técnico), donde T = 20°C y ||∇T|| = 0. Allí se instancian las rejillas perforadas de inyección de aire frío.
  • Puntos de mayor temperatura (Zonas Críticas): Ocurren en z = 3 (el techo), donde T = 29°C y ∇T = (0, 0, 6) con máxima dirección ascendente. Allí se instancian automáticamente los ventiladores de extracción.

4. Operador Divergencia y Expansión Térmica

El campo de flujo convectivo está modelado por F(x, y, z) = (0.5x, 0.2y, 1.5 + z).

div F = ∇ · F = ∂P/∂x + ∂Q/∂y + ∂R/∂z
div F = ∂(0.5x)/∂x + ∂(0.2y)/∂y + ∂(1.5 + z)/∂z
div F = 0.5 + 0.2 + 1.0 = 1.70 > 0

Dado que div F = 1.70 > 0 constante y positivo en todo el dominio Ω, el campo actúa como una fuente continua volumétrica, verificando físicamente la expansión del aire caliente hacia los extractores del techo, corroborado por el Teorema de la Divergencia de Gauss.
